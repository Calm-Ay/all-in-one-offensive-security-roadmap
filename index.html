THE BIG PICTURE
Phase 0 — Foundation · 1 week
Current Skills + Basic AI/Cloud Concepts
Web/API, exploits, malware dev, endpoint security and reverse engineering, plus basic AI knowledge as the launch pad.
Phase 1 — AI/LLM Offensive · 4–5 weeks
Prompt Injection → Agent Attacks → Advanced
Highest-leverage specialization right now: AI adoption is exploding but very few people can actually attack these systems effectively.
Phase 2 — Cloud Offensive · 4–5 weeks
IAM → Misconfigs → K8s/Serverless → CI/CD
Cloud is the new attack surface. Most companies are moving to cloud but very few pentesters know how to properly attack them.
Phase 3 — Integration · Ongoing
Attack Cloud-Hosted AI Systems
The power move: chain cloud IAM compromise → access to LLM endpoints → prompt injection / model extraction. Rare and valuable.
MUST-MASTER CONCEPTS
Phase 1 — AI / LLM Red Teaming
  • Prompt Injection (direct + indirect) & jailbreaking
  • RAG poisoning & data poisoning
  • Model extraction & membership inference
  • Agent / tool abuse & supply chain attacks on AI pipelines
  • Guardrail bypass & multi-turn / conversational attacks
  • Adversarial examples for LLMs & vision models
Phase 2 — Cloud Attack Surfaces
  • IAM — privilege escalation via roles, policies, trust relationships
  • Misconfigurations — S3 buckets, security groups, metadata service abuse
  • Container & Kubernetes — container escapes, RBAC, pod security
  • Serverless — event injection, permission boundaries, supply chain
  • CI/CD pipelines — pipeline compromise, secret exfiltration, poisoned builds
  • Storage & data services — S3/Blob attacks + snapshot abuse
